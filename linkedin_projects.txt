PROJET 1 : AfriDataHub
----------------------------------------------

Nom du projet : AfriDataHub — Plateforme Open Data Intelligence pour l'Afrique

Description :
Conception et développement de bout en bout d'une plateforme d'intelligence de données ouvertes qui centralise les données économiques, climatiques, sanitaires et agricoles des 54 pays africains à partir de plus de 10 sources officielles internationales (Banque mondiale, FAO, OMS, UNESCO). La plateforme propose un tableau de bord interactif avec cartes SVG, un moteur d'analyse alimenté par Google Gemini, des analyses prédictives par régression linéaire et un système de détection d'anomalies à 4 niveaux de gravité. Un pipeline IA autonome basé sur Groq automatise la recherche web et l'extraction structurée de données, tandis qu'un Studio interactif permet aux utilisateurs de transformer et nettoyer leurs jeux de données en temps réel. L'architecture complète (Django, DRF, React, PostgreSQL, Redis, Celery) a été déployée en production avec Docker sur des serveurs dédiés. Résultat : 54 pays couverts, plus de 160 jeux de données actifs et plus de 16 000 points de données disponibles pour les chercheurs, décideurs politiques et entreprises africaines.

Compétences :
Data Science, Data Analysis, Python, Django, React.js, JavaScript, TypeScript, PostgreSQL, Redis, REST APIs, API Development, Machine Learning, Artificial Intelligence (AI), Large Language Models (LLM), Generative AI, Data Visualization, Predictive Analytics, Docker, Software Architecture, System Design, Database Design, Data Modeling, Model Fine-Tuning, Prompt Engineering, Data Engineering, Web Development, Full-Stack Development, Git, GitHub, Agile Methodologies

PROJET 4 : EduShare
----------------------------------------------

Nom du projet : EduShare — Plateforme éducation open-source avec IA RAG

Description :
Conception et développement d'une plateforme open-source de partage de documents PDF intégrant un assistant IA RAG (Retrieval-Augmented Generation) zéro-dépendance, basé sur l'algorithme BM25 Okapi — sans aucune dépendance externe (pas de FAISS, LangChain ni base vectorielle). Le système réalise une extraction intelligente du texte page par page, un découpage intelligent (environ 180 mots avec chevauchement de 40 mots), et récupère les 5 passages les plus pertinents pour générer des réponses sourcées avec historique de conversation. La plateforme offre une recherche plein texte avec filtres (domaine, niveau, tags), une génération automatique de résumés, quiz et traductions par IA, des recommandations personnalisées, ainsi qu'une API REST publique avec quotas et plans d'abonnement. Des fonctionnalités sociales complètent le produit : commentaires, favoris, badges et notifications. Déployée en production avec Docker, la solution rend les ressources éducatives africaines plus accessibles et interactives.

PROJET 6 : FineTune Platform
----------------------------------------------

Nom du projet : FineTune Platform — SaaS de fine-tuning de LLM pour entreprises

Description :
Conception et développement d'une plateforme SaaS de niveau entreprise pour le fine-tuning de grands modèles de langage (LLM) utilisant les méthodes LoRA/QLoRA, démocratisant l'adaptation des modèles IA pour des besoins métiers spécialisés. La plateforme supporte 4 modèles de base (Llama 2 7B/13B, Mistral 7B, CodeLlama 7B) avec des hyperparamètres entièrement configurables (taux d'apprentissage, époques, taille de lot, rang/alpha/dropout LoRA). Les utilisateurs peuvent téléverser leurs jeux de données en CSV/JSON/JSONL avec validation automatique, suivre les métriques d'entraînement en temps réel (loss, perplexité) et gérer les artefacts générés (poids LoRA, configurations, métriques). L'infrastructure supporte le GPU haute performance ou le CPU standard. Le système intègre Stripe avec un système de crédits (Starter 100 / Pro 500), des remboursements automatiques en cas d'échec et 100 crédits gratuits pour les nouveaux utilisateurs. Déployée en production avec Docker, la plateforme supprime les barrières techniques et financières au fine-tuning.
